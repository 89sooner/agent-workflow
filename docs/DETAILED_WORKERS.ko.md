# 작업자 3D 형상과 관제실 시점 개선

2026-11-04. 별도 브랜치 `feat/detailed-workers-20261104`에서 구현했다. origin/main 통합 대상이다. 운영 서버 배포는 별도이며 실행 중인 서버는 재시작하지 않는다.

## 변경 내용

1. 기본 카메라를 얼굴이 보이는 앞·측면으로 바꾸고 모니터를 옆으로 옮겼다. 선택한 작업자 확대와 시점 초기화 버튼을 추가했다.
2. 둥근 몸체, 목, 바이저와 눈, 측면 부품, 어깨·팔꿈치 관절, 손바닥·세 손가락, 앉은 다리와 신발을 구성했다. 팔 높이와 타이핑 진폭을 조정하고 키보드를 책상 표면 위에 배치했다.
3. 화면 좌표에 고정 크기 이름표를 표시한다. 화면 경계 안으로 배치하고 겹치면 선택 작업자를 우선한 뒤 주변 이름표를 숨긴다. 이름표 클릭으로도 작업자를 선택할 수 있다. 긴 이름은 말줄임하고 마우스를 올리면 전체 이름·역할을 확인한다. 선택한 작업자의 전체 이름·역할·상태는 캔버스 밖에도 표시하여 작은 화면에서도 읽을 수 있게 했다. 가슴 배지 모양으로 리뷰·검사·기타 역할을 구분한다.
4. 부위별 거칠기·금속성과 조명을 조정했다. 원격 모델이나 텍스처는 추가하지 않았다.
5. 작업자별 여섯 손가락이 geometry/material을 공유한다. 카메라에서 먼 작업자는 손가락을 생략하지만 선택한 작업자는 유지한다. 렌더링 호출·삼각형 수를 캔버스 부모의 data-draw-calls/data-triangles로 확인할 수 있다.

## 사용 방법

1. 관제실의 작업 목록에서 작업을 선택한다.
2. 작업 그래프 또는 3D 작업자를 선택한다.
3. **선택한 작업자 가까이**로 얼굴과 손을 확대한다.
4. 드래그로 회전하고 휠로 거리를 조정한다. **시점 초기화**로 기본 구도로 돌아간다.
5. 캔버스 밖의 전체 이름·역할·상태와 기존 실행 상세·이력을 함께 확인한다.

선택 가능한 작업자가 없으면 확대 버튼은 비활성화된다. 움직임 줄이기, 숨긴 탭, 연결 단절 시의 기존 동작을 유지한다.

## 검증과 제한

타입 검사, 번들 빌드 및 소스 일치 검사, 실제 Chromium 관제실 회귀 검사를 통과했다. 회귀 검사에 선택 이름과 확대·초기화 버튼 동작을 추가했다. 기존 실행 fixture, 실시간 움직임, 줄인 움직임, 숨긴 탭, 단절·복구, 이력, 원장 전환, 모바일, 키보드, WebGL fallback 검사도 통과했다.

읽기 전용 미리보기는 http://127.0.0.1:8885/mission 이며 state home은 /tmp/agent-workflow-workers-preview-20261104 다. 임시 프로세스이므로 재시작 후에는 다시 실행해야 할 수 있다. 운영 서버와 큐 worker는 변경하지 않는다.

## 다수 작업자 측정

운영 원장과 분리된 합성 장면을 실제 Headless Chromium / ANGLE SwiftShader에서 검사했다. 1440×900 뷰포트, 높이 500px 캔버스, 작업자 1명 선택 상태에서 장면당 워밍업 후 90개 requestAnimationFrame 간격을 수집했다.

| 입력 / 표시 인원 | draw calls | 삼각형 | 프레임 간격 중앙값 / p95 |
|---|---:|---:|---:|
| 1 / 1 | 43 | 4,096 | 16.7 / 16.7ms |
| 4 / 4 | 151 | 15,604 | 16.7 / 33.4ms |
| 12 / 12 | 417 | 44,988 | 33.3 / 66.7ms |
| 24 / 12 | 417 | 44,988 | 33.4 / 66.7ms |

측정 당시 다른 회귀 검사도 실행 중이었다. rAF 간격은 GPU 실행 시간이나 실제 기기의 FPS 보증이 아니다. 12명에서는 약 33ms 간격이므로 소프트웨어 렌더러에서 60fps 목표를 만족한다고 할 수 없다. 저사양 하드웨어 장시간 실행·개선 전후 비교는 아직 측정하지 않았다. 부담이 크면 **움직임 줄이기** 또는 **3D 공간** 끄기를 사용한다.

각 인원에서 기본·확대·390px 모바일·드래그 회전·휠 확대 화면의 이름표 경계와 상호 비겹침, 선택 우선, 12명 상한, 상한 밖 마지막 작업자 선택 보존, 움직임 정지 시 화면 안정성과 갱신·Enter 선택 후 이름표 키보드 포커스 보존을 확인했다. 보이지 않는 주변 이름표는 담당자 목록·그래프로 선택하면 우선 표시된다. 화면 뒤쪽 작업자는 이름표를 표시하지 않는다.
